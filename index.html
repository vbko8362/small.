Small Bot — Privacy Policy

Last updated: November 10, 2026

1. Introduction

Small is a Discord bot designed to help Discord communities share images from publicly accessible Pinterest boards.

2. Information We Access

Small may access Discord server and channel IDs, user IDs needed for bot features, messages containing Pinterest board links, and public Pin information and image URLs retrieved through the Pinterest API.

Discord members do not need to connect their own Pinterest accounts.

3. How Information Is Used

Small uses this information to detect Pinterest board links, retrieve available Pins through the Pinterest API, share images in the configured Discord channel, and remember server settings.

4. Data Storage

Small stores certain bot settings in a local database, including server configuration and channel settings. Do not assume that no other information is stored; the bot's actual data practices should be reviewed before this policy is published.

5. Third-Party Services

Small uses Discord to provide bot features and Pinterest's API to retrieve authorized Pinterest content. Their own privacy policies and terms also apply.

6. Data Security

Reasonable measures are used to protect stored information and configuration. Access credentials should be kept private.

7. Changes

This policy may be updated as Small's features or data practices change.
